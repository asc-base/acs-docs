# Data Science Roadmap

## เป้าหมาย

1. สร้างพื้นฐานด้านการเขียนโค้ด, คณิตศาสตร์เบื้องต้น และการเข้าใจข้อมูล
2. รู้วิธีทำงานกับข้อมูลจริงที่ซับซ้อน และเตรียมให้พร้อมสำหรับการสร้างโมเดล
3. Core ML Algorithm และทำโปรเจกต์จริง
4. ยกระดับให้ใช้ ML แก้ปัญหาธุรกิจจริง พร้อม deployment

## พื้นฐาน

### Programming (Python for Data Science)

- Data types, loops, functions, OOP
- Libraries: pandas, numpy, matplotlib, seaborn

### Math & Statistics for DS

- Probability, Distribution
- Descriptive Statistics
- Hypothesis Testing

### SQL & Data Engineering Basics

- Select, Join, GroupBy
- Basic ETL concepts

## Data Engineering + Data Manipulation

### Data Engineering Tools

- Data Pipeline Concept
- ใช้ Airflow หรือ Prefect เบื้องต้น
- Cloud Storage

### Data Cleaning & Feature Engineering

- Handling missing values
- Encoding categorical features
- Feature scaling

## Machine Learning

### Supervised Learning

- Linear Regression, Logistic Regression
- Decision Trees, Random Forest
- Gradient Boosting (XGBoost, LightGBM)

### Unsupervised Learning

- KMeans, Hierarchical Clustering
- PCA, Dimensionality Reduction

### Model Evaluation

- Cross-validation, Precision/Recall, AUC, Confusion Matrix

## Advanced + Business Application

### Business Problem Framing

- แปลง Business Question → Data Problem
- KPI & ROI จาก Data Project

### MLOps & Deployment

- Model serving ด้วย FastAPI หรือ Flask
- Model Monitoring
