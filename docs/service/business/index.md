# Business Analytics Roadmap

## เป้าหมาย

1. กำหนดปัญหาธุรกิจ นิยามเป้าหมาย และจัดลำดับความสำคัญได้
2. ออกแบบ As Is/To Be process, data model ระดับ feature
3. ดำเนินการ elicitation (interview/workshop) และสังเคราะห์ความต้องการเป็น epic/user stories
4. จัดทำ backlog เชื่อม traceability
5. สื่อสารกับ Dev/QA/Stakeholders + โปรโตไทป์/ไดอะแกรมที่จำเป็น

## พื้นฐาน

- พื้นฐาน BA
- Product Thinking
- SDLC/Agile vs Waterfall
- คำศัพท์ธุรกิจ

## Elicitation

- Interview
- Observation
- Document Analysis

## Business basic

- Process Modeling (BPMN), SIPOC, Value Stream
- Problem Framing & Root Cause (5 Whys, Fishbone), Impact Mapping

## Requirement engineering

- To Be Design, Optioning & Trade offs
- Requirements Engineering, Use Case vs User Story
- NFR (Performance, Security, Legal, Usability)

## Related Skills for BA

- UX for BA: Persona, Journey, Wireframe/Prototype (Low fi)
- Data for BA: ERD พื้นฐาน, Data Dictionary, API Basics
- Analytics & Metrics: KPI Tree, Tracking Plan, A/B test basics
- QA for BA: Test Scenarios, BDD, UAT Planning, Traceability

## Change management

- Change/Scope control, Risk & Decision log, Compliance
